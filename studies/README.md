# Intervention studies

Each folder is one study: does accurate, sourced material published about a text reach AI answers, how fast, and through which models? Design, controls and ethics: [docs/intervention-study.md](../docs/intervention-study.md).

```
studies/<id>/
  study.json                 design, fixed before the first intervention (schema/study.schema.json)
  interventions.jsonl        the intervention log (schema/intervention.schema.json)
  intervention_status.jsonl  daily checks: still online, still contains check_text, current revision, indexed
  runs/<date>/<run-id>/      daily runs: run.json, calls.jsonl, responses.jsonl, scores.json
  timeseries.jsonl           daily aggregates (generated by scripts/analyze_study.py)
  REPORT.md, report.json     effects per intervention, model and mode (generated)
```

## Running a study

1. Write the items (a text track's `dev` split, reviewed) and copy `example-37-practices/study.json`. Pick control items and planned targets at random, set the panel, and set `status: "planned"`.
2. Set `status: "baseline"` at least 7 days before the first intervention. The daily workflow starts running the panel.
3. Publish an intervention, then add its line to `interventions.jsonl` the same day with `status: "live"` and the exact `published_at`. Set the study to `status: "running"`.
4. Never edit past runs. Changes to the design go in `amendments` with a date.
5. Set `status: "ended"` when the study is over; the report stays.

Before publishing anything, read the ethics section of the design doc: accurate and sourced content only, disclose conflicts of interest, follow each Wikipedia's policies, and log reverts instead of undoing them.

`example-37-practices` is a format example: its interventions are not real publications.
