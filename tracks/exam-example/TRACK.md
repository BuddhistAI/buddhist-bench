# Exam track (format example)

An exam track holds questions from real exam papers set by a monastery, Buddhist university, shedra or national exam system, so models are tested the way students are. This one is a fictional format example.

One exam track per institution or exam system (e.g. `nak-tham` for the Thai national Dhamma exams). `papers.json` describes each paper and its permission; items carry `exam: {paper, question, marks, marking}`.

How to build a real one: see [docs/exams.md](../../docs/exams.md).
